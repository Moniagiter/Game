# Морський бій (Sea Battle)

## 1. Опис гри
"Морський бій" — це класична гра, де гравець має знищити всі кораблі супротивника, стріляючи по клітинках сітки.

### Вимоги:
- **Ціль гри:** Знищення всіх кораблів супротивника.
- **Ігрове поле:** Стандартне поле розміром 10x10.
- **Кораблі:** 
  - Різного розміру (2, 3, 4 клітинки).
  - Кораблі розташовані випадково на сітці.
  - Частини кораблів не перетинаються.
- **Механіка гри:** 
  - Гравець вводить координати (наприклад, "A1").
  - Якщо координата потрапляє в корабель, клітинка позначається символом `'X'` (для людини) або `'='` (для комп'ютера).
  - Якщо корабель потоплено, всі його частини позначаються символом `'-'` (для людини) або `'*'` (для комп'ютера).
  - Якщо гравець промахнувся, клітинка позначається `'O'` (для людини) або `'#'` (для комп'ютера).
  - Гра завершується, коли всі кораблі одного з гравців потоплено.


## 2. Модульний дизайн гри
Гра побудована на принципах модульності та розширюваності. Нижче наведено список основних модулів:

### Інтерфейси та класи:
#### 1. Game

Основна логіка гри.
Контролює хід гри, викликаючи функції інших модулів.
Взаємодіє з гравцями (людиною і комп'ютером).  
Методи:
- `startGame()`: Запускає основний цикл гри.  
- `playTurn(player: Player, ships: List<Ship>, board: Board, hitSymbol: char, missSymbol: char, sunkSymbol: char): boolean`: Виконує хід одного гравця.


#### 2. Board (інтерфейс) та реалізації: HumanBoard, ComputerBoard  

Відповідають за управління сіткою (ігровим полем) для гравця і комп'ютера.
Зберігають інформацію про стан клітинок (влучання, промахи тощо).
Методи:
- `updateGrid(int x, int y, char symbol)`: Оновлює стан клітинки.
- `display()`: Відображає сітку в консолі.


#### 3. Ship (інтерфейс) та реалізація ReguarShip

Визначає загальні дії для кораблів.  
Методи:
- `isHit(int x, int y): boolean`: Перевіряє, чи є попадання в корабель.
- `isSunk(): boolean`: Перевіряє, чи корабель потоплений.
- `getCoordinates(): List<int[]>`: Повертає координати корабля.


#### 4. Player (інтерфейс) та реалізації: ConsolePlayer, ComputerPlayer

**ConsolePlayer**:
- Відповідає за отримання введення від людини.  
- Методи:
  - `getCoordinates()`: Зчитує введення від гравця та перетворює його у числовий формат.

**ComputerPlayer**:
- Використовує стратегію для вибору клітинок: випадковий вибір або добивання корабля.  
- Методи:
  - `getCoordinates()`: Вибирає координати для атаки.
  - `onHit(int x, int y)`: Зберігає інформацію про попадання.
  - `onMiss()`: Змінює напрямок або обирає нову ціль.


#### 5. BoardGenerator (інтерфейс) та реалізації: RandomBoardGenerator, ComputerBoardGenerator

Відповідають за створення списку кораблів.  
- `RandomBoardGenerator`: Генерує кораблі для поля гравця.
- `ComputerBoardGenerator`: Генерує кораблі для поля комп'ютера.

Методи:
- `generate(): List<Ship>`: Генерує список кораблів.
