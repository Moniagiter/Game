# Морський бій (Sea Battle)

## 1. Опис гри
"Морський бій" — це класична гра, де гравець має знищити всі кораблі супротивника, стріляючи по клітинках сітки.

### Вимоги:
- **Ціль гри:** Знищення всіх кораблів супротивника.
- **Ігрове поле:** Стандартне поле розміром 10x10.
- **Кораблі:** 
  - Різного розміру (1, 2, 3, 4 клітинки).
  - Кораблі розташовані випадково на сітці.
  - Частини кораблів не перетинаються.
- **Механіка гри:** 
  - Гравець вводить координати (наприклад, "A1").
  - Якщо координата потрапляє в корабель, клітинка позначається символом `'X'`.
  - Якщо корабель потоплено, всі його частини позначаються символом `'-'`.
  - Якщо гравець промахнувся, клітинка позначається `'O'`.
  - Гра завершується, коли всі кораблі потоплено.

## 2. Модульний дизайн гри
Гра побудована на принципах модульності та розширюваності. Нижче наведено список основних модулів:

### Інтерфейси та класи:
1. Game

Основна логіка гри.
Контролює хід гри, викликаючи функції інших модулів.
Взаємодіє з гравцем через консоль.  
Методи:

startGame(): Запускає основний цикл гри.  
playTurn(): Виконує один хід гравця.  

2. Grid (інтерфейс) та RegularBoard (реалізація)  

Відповідає за управління сіткою (ігровим полем).
Зберігає інформацію про стан клітинок (влучання, промахи тощо).
Методи:

updateGrid(int x, int y, char symbol): Оновлює стан клітинки.
display(): Відображає сітку в консолі.

3. Ship (інтерфейс) та ReguarShip (реалізація)

Визначає загальні дії для кораблів.
Методи:

isHit(int x, int y): Перевіряє, чи є попадання в корабель.
isSunk(): Перевіряє, чи корабель потоплений.
getCoordinates(): Повертає координати корабля.

4. Player (інтерфейс) та ConsolePlayer (реалізація)

Відповідає за отримання введення від гравця.
Забезпечує валідацію координат.
Методи:

getCoordinates(): Зчитує введення від гравця та перетворює його у числовий формат.

5. BoardGenerator (інтерфейс) та RandomBoardGenerator (реалізація)

Відповідає за створення списку кораблів.
Кораблі розташовуються випадковим чином на полі
